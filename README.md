# 🧠 Ứng dụng AI Ngoại Tuyến (Offline AI)

Đây là ứng dụng mẫu viết bằng **Kotlin**, chạy hoàn toàn **ngoại tuyến** trên Android.  
Ứng dụng hiển thị thông báo "Chào mừng bạn đến với AI Ngoại Tuyến!".

---

## 🔧 Cách cài đặt

1. Tải mã nguồn này về (nhấn **Code → Download ZIP**)  
2. Giải nén file ZIP  
3. Mở bằng **Android Studio**  
4. Nhấn **Run ▶️** để cài trực tiếp lên điện thoại Android.

---

## 📱 Yêu cầu
- Android 7.0 trở lên  
- Android Studio mới nhất
